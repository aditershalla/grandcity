# Grand City 🎮

A responsive, light-themed gaming accessories storefront demo.

## Features
- Clean white-and-blue design
- Product search and category filters
- Demo shopping cart
- Responsive layout for mobile and desktop
- Static HTML/CSS/JavaScript, no build tools needed

## Preview
Open `index.html` in a browser.

## Publish free with GitHub Pages
Go to **Settings → Pages → Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, and save. Once enabled, the expected URL is https://aditershalla.github.io/grandcity/.

## Shopify later
This is a standalone prototype, not a Shopify theme yet. A Shopify theme or Storefront API integration will be required for real inventory and checkout.

## Disclaimer
Product images, names, and prices are illustrative placeholders. Real checkout, supplier fulfillment and payments are not connected. Do not accept real orders until payments, shipping, tax and refund policies are ready. Not affiliated with Rockstar Games, Sony, or Microsoft.
